# Sprite Pet

First-draft Rust/egui Tamagotchi-style game. It uses `assets/sprite_frame_1.png`, `assets/sprite_frame_2.png`, `assets/sprite_frame_3.png`, and `assets/button_1.png` through `button_3.png` as placeholders for the supplied 8x8 PNGs. The app remains runnable with labelled fallback buttons and a `PET` placeholder until those files are provided.

Install Rust, add the PNGs at those paths, and run:

```powershell
cargo run
```
